# Actors

| Actor  | Prefix | Description                                                                 |
|--------|--------|-----------------------------------------------------------------------------|
| User   | USR    | A person (investor or tradie) who uses the app to analyse property plans    |
| System | SYS    | Automated processes (e.g., image recognition, calculations, scheduled jobs) |
| Stripe | EXT    | External payment provider — manages subscription billing, payment methods, and plan lifecycle via webhooks and hosted UI |
| Admin  | ADM    | The business owner or developer who manages application configuration via external platforms such as the Stripe Dashboard |
